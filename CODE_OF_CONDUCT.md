# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. By participating in this repository — issues, pull
requests, discussions, or any other forum operated under this project — you
agree to abide by its terms.

The full text is maintained upstream and applies in its entirety:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Reporting

To report unacceptable behavior, contact the maintainers privately at
**merchantsuccess@easypaydirect.com**. Reports are reviewed confidentially. We follow the
Enforcement Guidelines published with the Covenant.

For security vulnerabilities (not conduct), see [SECURITY.md](./SECURITY.md)
instead.

## Scope

This Code of Conduct applies in all project spaces and when an individual
is officially representing the project in public spaces.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
